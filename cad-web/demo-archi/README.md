# Digital Canvas Studio

dessine webapp fictive qui consiste en un frontend web studio SaaS qui fait de l'édition de matrices 3D webGL d'un batiment numérique. 

le preview doit etre interactif, pas static.

pouvoir faire tourer la matrice dans le canvas 3D. 

features: 

login  (admin@example.com / 1234)

liste des projets

quota disk + alert orange 80% utilisé

top center alert quand on clique bouton "save project".

une liste de commentaire dans une colonne de type drawer flottant émis par ds clients des collaborateurs,

partager une matrice avec un collègue, avec un tiers (avec popup a la maniere de partage Google doc, partage Notion page) a partir d'une liste préremplie et fictive

le rendu doit etre celui d'un progiciel en SaaS très pro et élégant, waoo effect
